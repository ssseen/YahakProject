* **해결 방법**: Learning Rate를 낮추고 데이터 전처리(16kHz 리샘플링)를 더욱 엄격하게 통제하여, 최종적으로 발산 없이 안정적인 성능(94.5%)을 확보하는 데 성공했습니다.
